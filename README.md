# Mijn Kozijnrenovatie

Custom prototype voor een moderne visuele kozijnrenovatie-configurator.

## Bestanden

- `index.html` - one-page website en configurator-HTML
- `styles.css` - visuele styling en responsive layout
- `app.js` - stappenlogica en live SVG-preview

## Lokaal testen

Open `index.html` direct in je browser of gebruik VS Code met Live Server.

## Vercel

Dit is een statische website. In Vercel kun je deze repo direct importeren:

- Framework preset: `Other`
- Build command: leeg laten
- Output directory: leeg laten / root
